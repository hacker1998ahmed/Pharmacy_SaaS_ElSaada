# نظام إدارة الصيدلية المتكامل - Pharmacy Management System

## 📋 نظرة عامة على المشروع

نظام متكامل لإدارة الصيدليات يشمل جميع الجوانب التشغيلية والإدارية والمالية.

## 🎯 المميزات الرئيسية

### 1. إدارة المخزون
- تتبع الأدوية والمنتجات
- تنبيهات انتهاء الصلاحية
- تنبيهات نقص المخزون
- تصنيف المنتجات حسب الفئات

### 2. المبيعات والفواتير
- نقطة بيع (POS) سريعة
- فواتير مفصلة
- دعم الباركود
- خصومات وعروض

### 3. إدارة العملاء
- سجل العملاء
- الوصفات الطبية
- تاريخ الشراء
- نظام الولاء

### 4. التقارير والتحليلات
- تقارير المبيعات اليومية/الشهرية
- تقارير المخزون
- تحليل الأرباح
- إحصائيات الأداء

### 5. إدارة المستخدمين
- صلاحيات متعددة المستويات
- سجل الدخول والخروج
- تتبع الأنشطة

## 🏗️ هيكل النظام

```
pharmacy-system/
├── index.html          # الصفحة الرئيسية
├── css/
│   └── style.css       # ملفات التنسيق
├── js/
│   ├── app.js          # الكود الرئيسي
│   ├── inventory.js    # إدارة المخزون
│   ├── sales.js        # المبيعات
│   └── reports.js      # التقارير
├── assets/
│   ├── images/         # الصور
│   └── icons/          # الأيقونات
└── README.md           # دليل الاستخدام
```

## 🚀 التقنيات المستخدمة

- HTML5
- CSS3 مع تصميم متجاوب
- JavaScript (Vanilla ES6+)
- LocalStorage لتخزين البيانات
- Chart.js للرسوم البيانية
- Font Awesome للأيقونات

## 📦 التثبيت والتشغيل

1. افتح ملف `index.html` في المتصفح
2. لا حاجة لخادم أو تثبيت إضافي
3. البيانات تحفظ محلياً في المتصفح
