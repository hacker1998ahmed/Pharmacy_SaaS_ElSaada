## 🔐 نظام الأمان والصلاحيات

### مستويات الوصول:
1. **مدير النظام (Admin)**
   - صلاحيات كاملة
   - إدارة المستخدمين
   - الوصول لجميع التقارير
   - الإعدادات العامة

2. **صيدلي (Pharmacist)**
   - إدارة المخزون
   - المبيعات والفواتير
   - تقارير المبيعات
   - لا يمكنه حذف بيانات

3. **كاشير (Cashier)**
   - نقطة البيع فقط
   - عرض المنتجات
   - لا يمكنه تعديل الأسعار
   - تقارير يومية محدودة

### ميزات الأمان:
- ✅ تشفير كلمات المرور
- ✅ جلسة مستخدم آمنة
- ✅ سجل عمليات (Log)
- ✅ مهلة الجلسة التلقائية

## 💊 إدارة المخزون المتقدمة

### تتبع المنتجات:
- **الباركود**: دعم كامل لأنظمة الباركود
- **تواريخ الانتهاء**: تنبيهات قبل 30 يوم
- **الكميات**: تحديث تلقائي مع كل بيع
- **الأسعار**: هامش ربح تلقائي الحساب

### الفئات المدعومة:
```
📦 مسكنات والألم
💊 مضادات حيوية
🧴 مستحضرات تجميل
💉 أجهزة طبية
🍽️ مكملات غذائية
❤️ أدوية قلب
🤧 أدوية برد وإنفلونزا
👶 منتجات أطفال
```

### التنبيهات الذكية:
- 🔔 نقص المخزون (أقل من الحد الأدنى)
- 🔔 انتهاء الصلاحية (خلال 30 يوم)
- 🔔 نفاد الكمية تماماً
- 🔔 منتجات راكدة (لم تباع منذ 3 أشهر)

## 🛒 نقطة البيع (POS) الاحترافية

### سرعة الأداء:
- ⚡ بحث فوري بالاسم أو الباركود
- ⚡ إضافة للسلة بنقرة واحدة
- ⚡ تحديث فوري للإجماليات
- ⚡ طباعة فورية للفواتير

### طرق الدفع:
- 💵 نقدي
- 💳 بطاقة ائتمان/خصم مباشر
- 🏦 تحويل بنكي
- 📱 محافظ إلكترونية

### خصومات وعروض:
- خصم بالنسبة المئوية
- خصم بقيمة ثابتة
- عروض "اشترِ X واحصل على Y"
- كوبونات خصم

## 📈 التقارير والتحليلات

### لوحة التحليلات:
```
┌─────────────────────────────────────┐
│        أداء هذا الشهر              │
├─────────────────────────────────────┤
│ إجمالي المبيعات:    45,230 ر.س    │
│ عدد الفواتير:          342 فاتورة │
│ متوسط الفاتورة:        132 ر.س    │
│ صافي الربح:           12,450 ر.س   │
│ هامش الربح:            27.5%      │
└─────────────────────────────────────┘
```

### أنواع التقارير:

#### 1. التقارير المالية:
- تقرير المبيعات اليومي
- تقرير الإيرادات الشهري
- تقرير الأرباح والخسائر
- تدفق النقدي

#### 2. تقارير المخزون:
- قيمة المخزون الحالي
- حركة المخزون (دخل/خرج)
- المنتجات الأكثر مبيعاً
- المنتجات الراكدة
- نسبة الهلاك

#### 3. تقارير الأداء:
- أداء الموظفين
- أفضل أوقات الذروة
- مقارنة الفترات
- تحقيق الأهداف

#### 4. تقارير العملاء:
- العملاء الأكثر شراءً
- معدل العودة
- قيمة عمر العميل (LTV)
- تحليلsegments العملاء

### تصدير البيانات:
- 📄 PDF للطباعة
- 📊 Excel للتحليل
- 📧 Email مباشرة
- 🖨️ طباعة فورية
