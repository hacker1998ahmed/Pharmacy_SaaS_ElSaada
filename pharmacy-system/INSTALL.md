## 🔧 خطوات التثبيت

### الطريقة 1: التشغيل المباشر (الأسهل)

```bash
# 1. انسخ مجلد النظام إلى جهازك
cp -r pharmacy-system /path/to/your/location

# 2. افتح ملف index.html في المتصفح
# انقر مرتين على الملف أو استخدم:
google-chrome pharmacy-system/index.html
```

**✅ المميزات:**
- لا يحتاج تثبيت
- يعمل فوراً
- لا حاجة لخادم

**⚠️ ملاحظة:** البيانات تحفظ في LocalStorage للمتصفح فقط

---

### الطريقة 2: استخدام خادم محلي

#### خيار A: Python SimpleHTTPServer

```bash
# للمطورين والمستخدمين المتقدمين
cd pharmacy-system

# Python 3
python3 -m http.server 8080

# افتح المتصفح على:
# http://localhost:8080
```

#### خيار B: Node.js Live Server

```bash
# تثبيت live-server عالمياً
npm install -g live-server

# تشغيل الخادم
cd pharmacy-system
live-server --port=8080
```

#### خيار C: PHP Built-in Server

```bash
cd pharmacy-system
php -S localhost:8080
```

---

### الطريقة 3: التثبيت كبرنامج سطح مكتب

#### باستخدام Electron:

```bash
# 1. تثبيت Electron
npm init -y
npm install electron --save-dev

# 2. إنشاء ملف main.js
cat > main.js << 'ELECTRON'
const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: { nodeIntegration: true }
  });
  
  win.loadFile('index.html');
}

app.whenReady().createWindow);
ELECTRON

# 3. تحديث package.json
# أضف: "main": "main.js"

# 4. تشغيل التطبيق
npx electron .
```

## ⚙️ الإعداد الأولي

### 1. تشغيل النظام لأول مرة

```
1. افتح index.html
2. سجل الدخول بـ: admin / admin123
3. انتقل للإعدادات
4. أدخل بيانات الصيدلية
```

### 2. تخصيص البيانات

```yaml
بيانات الصيدلية:
  - الاسم: "صيدلية ___"
  - العنوان: "___"
  - الهاتف: "___"
  - البريد: "___"
  - العملة: "ر.س / ج.م / د.إ"
```

### 3. إضافة المنتجات الأولى

```
1. اذهب لإدارة المخزون
2. اضغط "إضافة منتج جديد"
3. أدخل 10-20 منتج على الأقل
4. حدد الفئات المناسبة
```

### 4. إعداد المستخدمين

```
1. الإعدادات > المستخدمين
2. أضف الصيادلة والكاشير
3. حدد صلاحيات كل مستخدم
4. وزع كلمات المرور
```

## 🔄 النسخ الاحتياطي

### تصدير البيانات يدوياً:

```javascript
// في وحدة تحكم المتصفح (F12)
console.log(JSON.stringify(appData));
// انسخ الناتج واحفظه في ملف .json
```

### من واجهة النظام:

```
1. الإعدادات > النسخ الاحتياطي
2. اضغط "تصدير البيانات"
3. احفظ الملف في مكان آمن
4. كرر العملية أسبوعياً
```

### استعادة البيانات:

```
1. الإعدادات > النسخ الاحتياطي
2. اضغط "استيراد بيانات"
3. اختر ملف النسخة الاحتياطية
4. أكد العملية
```

## 🛠️ استكشاف الأخطاء

### مشكلة: النظام لا يعمل

```bash
# الحلول الممكنة:
1. تأكد من فتح الملف في متصفح حديث
2. امسح Cache المتصفح (Ctrl+Shift+Delete)
3. جرب متصفح آخر
4. تحقق من وجود أخطاء في Console (F12)
```

### مشكلة: البيانات تختفي

```bash
# الأسباب والحلول:
1. تم مسح بيانات المتصفح ← استعد من النسخة الاحتياطية
2. استخدام وضع التصفح الخاص ← استخدم التصفح العادي
3. تغيير المتصفح ← البيانات خاصة بكل متصفح
```

### مشكلة: الرسوم البيانية لا تظهر

```bash
# الحل:
1. تأكد من اتصال الإنترنت (Chart.js CDN)
2. حمل Chart.js محلياً:
   wget https://cdn.jsdelivr.net/npm/chart.js
3. عدّل index.html للإشارة للملف المحلي
```

### مشكلة: الطباعة لا تعمل

```bash
# الحل:
1. فعّل النوافذ المنبثقة في المتصفح
2. استخدم Chrome للطباعة الأفضل
3. تأكد من تعريف الطابعة
4. جرّب PDF أولاً
```
